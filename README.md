# Blood_Bank_Management
This DBMS project report details the design and implementation of an integrated Blood Bank Management and Hospital Transfer System. The system addresses critical healthcare challenges like fragmented donor records, supply shortages, and poor traceability by offering a centralized operational platform. It systematically records, tracks, and manages donors, individual donations, localized inventory across medical facilities, and inter-hospital blood transfers to prevent inventory wastage and optimize resource allocation.

The core architecture is built upon a well-defined conceptual database model consisting of key entities: Donors, Donations, Hospitals, Blood inventory pools, and Hospital Transfers. Using a normalized relational schema, the database establishes strict relational rules, foreign key constraints, and domain checks to guarantee data integrity, prevent operational errors, and ensure high operational consistency.

To make the system fully functional for healthcare administrators, the database is seamlessly integrated with an intuitive web-based front-end application built using Python's Flask framework. The user interface provides real-time tracking, low-stock warnings, donor registration forms, and streamlined routines for blood transfer requests between institutions.
